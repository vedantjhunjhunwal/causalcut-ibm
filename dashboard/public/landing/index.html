PLATFORM

Three layers between
a sensor reading and a saved life.

Every event flows through a deterministic pipeline — ingestion, analysis, and human-approved action — with full auditability at each stage.

01

Ingestion Spine

FastAPI endpoint ingests gas readings, machine states, worker permits, and zone events in real time. Async queue with backpressure writes to a SQLite WAL state store — no event is ever dropped.

FastAPI SQLite WAL AsyncIO
~2,400 events/min sustained throughput
02

Analytical Engine

Plant topology becomes a dynamic safety hypergraph in NetworkX. Four trained ML models (XGBoost, LightGBM, Isolation Forest) classify anomalies. OR-Tools solves the minimum causal cut. SimPy runs counterfactual simulations before anything is deployed.

NetworkX OR-Tools SimPy XGBoost LightGBM
<200ms cut computation end-to-end
03

Approval Gateway

Shift officers and safety managers review each recommendation through a role-based approval flow. Every decision — approved or rejected — is logged into a hash-chained, tamper-evident audit ledger for regulatory compliance.

RBAC Hash-Chained Audit Tamper-Evident
100% decision traceability
CUT ENGINE

The plant is a graph.
Every accident is a path.
We find the smallest cut.

CAUSALCUT models zones, machines, sensors, and workers as nodes in a safety hypergraph. Risk propagates along edges. The OR-Tools solver computes the mathematically minimal set of interventions that severs every high-risk pathway — without shutting down the entire line.
